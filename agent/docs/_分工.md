**`cross_reference` 工具实现（第2-4周）**

*第一阶段：语义相似度检索*
- [ ] 下载并集成 `paraphrase-multilingual-MiniLM-L12-v2` 模型（本地运行）
- [ ] 实现句子向量预计算（文章解析完成后一次性计算所有句子向量）
- [ ] 实现余弦相似度检索，找出语义最相关的 Top-K 句子
- [ ] 设置相似度阈值过滤（建议 > 0.6），避免无关句子干扰

```python
from sentence_transformers import SentenceTransformer
import numpy as np

class CrossReferenceTool:
    def __init__(self, sentences: list[ProcessedSentence]):
        self.model = SentenceTransformer(
            'paraphrase-multilingual-MiniLM-L12-v2'
        )
        self.sentences = sentences
        # 预计算所有句子向量（只算一次，后续查询复用）
        self.embeddings = self.model.encode(
            [s.text for s in sentences],
            batch_size=32,
            show_progress_bar=False
        )
    
    def retrieve_related(self, claim: str, top_k: int = 5) -> list[dict]:
        claim_vec = self.model.encode([claim])[0]
        scores = np.dot(self.embeddings, claim_vec) / (
            np.linalg.norm(self.embeddings, axis=1) * np.linalg.norm(claim_vec)
        )
        indices = np.argsort(scores)[::-1]
        results = []
        for idx in indices:
            if scores[idx] > 0.6 and self.sentences[idx].text != claim:
                results.append({
                    "sentence": self.sentences[idx],
                    "similarity": float(scores[idx])
                })
            if len(results) >= top_k:
                break
        return results
```

## 六、注意事项

### 安全规范

- **严禁**在代码中硬编码任何 API Key
- 所有 Key 通过环境变量加载：`os.getenv("TAVILY_API_KEY")`
- 仓库中提供 `.env.example` 文件说明需要配置的变量，`.env` 文件加入 `.gitignore`

### Git 协作规范

- 主分支：`main`（只接受 MR，不直接 push）
- 功能分支命名：`feature/人员字母-功能描述`（如 `feature/B-web-search-tool`）
- Commit 消息格式：`[模块] 简短描述`（如 `[agent-core] 实现 ReAct 循环主体`）
- 每个 MR 需要至少1人 Code Review 后才能合并

### 文档要求

- 每个模块需在 `docs/` 目录下维护对应的设计文档
- API 接口由 FastAPI 自动生成 Swagger UI（访问 `/docs`）
- 演示视频时长控制在 **5-10 分钟**，链接放在仓库根目录的指定位置
